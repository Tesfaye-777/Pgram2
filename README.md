# 江湖命格人生模拟器

一个娱乐向网页游戏 MVP。玩家输入姓名、出生日期、出生时辰和可选性别后，会生成命格档案，并进入 20 个原创人生关卡，通过选择、灵签效果与命骰判定推进自己的江湖人生。

> 仅供娱乐，不作为现实决策依据。所有命格、剧情与评价均为原创虚构游戏内容。

## 功能

- 首页入卷流程与资料填写
- 本地 mock 命格生成逻辑
- 命格词条、稀有度、倾向与命册详批
- 五维灵盘：福缘、财势、心性、魄力、悟性
- 20 个人生场景选择流程
- 隐藏选项、词条触发与命骰判定
- 每次选择影响五维属性和人生状态
- localStorage 保存当前档案与流程进度
- 最终命册、结局评价与渡劫记录

## 技术栈

- Next.js
- TypeScript
- Tailwind CSS
- localStorage

## 本地运行

```bash
bun install
bun run dev
```

启动后打开：

```text
http://localhost:3000
```
